- `npm run build`：vue-tsc 类型检查及 Vite 构建通过，没有新增依赖或变更锁文件。

- A4 独立浏览器 `npm run test:e2e -- knowledge-bases.spec.ts`：6 项通过，0 失败/跳过；真实页面、数据库与 jar 重启，非模拟业务接口。
- 浏览器全量 `npm run test:e2e`：16 项通过，0 失败/跳过（A3 认证 8 + A4 知识库 6 + A1 健康 2），实际耗时约 1.8 分钟。

开发中修正了测试断言把时间戳数字误判为账号 ID、Element Plus 确认结果类型声明，以及自动化点击选择框被显示层拦截和登录辅助函数丢弃返回路径的问题。改为正常点击选择控件，保留登录跳转 URL；没有用强制点击或增加重试掩盖失败。还加固了删除/退出期间的迟到响应，以及恢复焦点时不丢失尚未保存的编辑表单。

## 数据保护与兼容性

- 全部首次创建、跨用户数据、迁移/重启和浏览器删除都在临时独立测试数据库完成。用户真实 mianmian 密码从未读取、改写或用于自动测试。
- 普通开发容器 medical-rag-postgres 及其命名卷不参与测试。启动器结束只清理本次拥有的测试容器、匿名卷、Java/Vite/控制进程；不停止实际网站。
- 新增迁移仅 V3，不修改 V1/V2 或 users，不 seed 管理员；保留单管理员约束。知识库 owner_id 外键 RESTRICT，没有 ON DELETE CASCADE。
- A2 后端认证与错误处理文件原样；知识库错误处理单独限定控制器，不改变 A2 格式。原需求与分阶段计划原样。
- A1 健康测试预期迁移版本从 2 更新为 3；A3 待开发导航数从 7 更新为 6，其他认证验证保留。
- 密码、CSRF、Cookie/私有资料不写入浏览器本地存储；认证 trace 关闭，运行日志/图片/构建/数据库/.env 均排除提交。

3. Session 实际闲置过期只在隔离实例 1 分钟配置等待 65 秒，正式仍 30 分钟；未重复完整等待正式超时。未验证其他浏览器引擎或 Node 22。
4. 页面网络故障通过浏览器明确中断请求验证，未关闭用户真实数据库。跨用户夹具只有隔离测试事务，产品无第二管理员注册入口。
5. 当前库刷新恢复以详情 URL 为依据；首页刷新无库 ID 时需重新选择。未引入持久化浏览器缓存。
