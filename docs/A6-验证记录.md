## 文件与数据库一致性

1. 上传在知识库锁下先提交 UPLOADING 记录及 A5 生成的唯一 storage_key，之后锁库重新校验未删除、流式写入、哈希校验和 PDFBox 验证，最终提交 ACTIVE/PENDING 元数据。开始文件 I/O 前已有服务器定位凭据。
2. 上传/数据库激活失败触发精确补偿；补偿失败保留原定位记录，标记 DELETE_FAILED 并返回 UPLOAD_CLEANUP_PENDING，列表可显式重试。数据库不可用导致暂时无法更新状态时，原 UPLOADING 意图仍保留，不声称上传成功。
3. 删除先持久化 DELETING，读取接口立即拒绝，再清理指定原件后移除记录。文件清理失败保存 DELETE_FAILED/cleanup_error；文件已删但 DB 移除失败时，重试在已提交删除意图下允许原件不存在，完成记录移除。
4. 未完成的意图凭据可清理该 UUID 的正式/临时原件；不扫盘、不递归删未知文件。未知临时内容导致明确失败并保留记录，不能靠清空目录掩盖。
5. 删除知识库先提交 deletion_pending 及文献失效状态，保留库归属至各项清理完成，再检查没有资料记录并删除库。每一步按知识库锁协调，与上传使用同一锁；先开始上传则删除等待并纳入该文献，先标记删除则后续上传拒绝。K2 不受 K1 清理影响。
6. 网页确认前获取真实数量并携带期望数量；确认期间数量变化返回 409、本次不删除。A7 通过 KnowledgeBaseMaterialCleaner 接入真实医学图片清理，不建立假表或假图片清理。

只有 ACTIVE 文献可预览/下载及计入 documentCount；UPLOADING、DELETING、DELETE_FAILED 的处理状态仍与删除状态分开，并单独计入 pendingCleanupCount。成功上传的处理状态只有 PENDING，尚无文本处理、索引或重处理按钮。

## 开发期间发现和修正

- multipart 参数检查须通过 WebUtils 获取被安全包装器包裹的真实 multipart 请求；文件集合校验同时适配实际 Servlet 和 MockMvc，拒绝额外业务字段/多文件。真实 HTTP 测试覆盖容器限制及中文 413；超限错误在控制器选择前发生，新增只处理该异常的全局映射，不改变 A2 认证格式。
- PDFBox 会通过高层 Catalog 包装器修复一类非法 Type；补充包装器前的原始 Root/Pages 类型检查和页树实际数量核验，损坏结构专项通过，未降低为只看签名。
- Element Plus InputNumber 在首次挂载时固定部分 ARIA 状态；改为实际页数加载后才挂载，保证可访问性及真正可输入。页码 query 变化不重新销毁整份预览，切文献才释放/重载。
- 合成 PDF 生成器的内部随机文档 ID 使“重新生成”与“同一原件”不同；测试缓存一份合成原件再逐字节比较，业务原件不改动。MockMvc 会清空请求线程的认证上下文，直接服务重试测试显式恢复测试上下文，不改产品认证。
- Playwright 不接受超过 50 MiB 的内存文件参数；超限测试改为临时磁盘合成文件并实际选择，未删除超限断言或放宽大小限制。
- 二进制失效场景通过真实服务端注销使 Session 失效，再触发受保护原文请求，而非仅伪造一次 401 后让仍有效的会话被路由守卫重新确认；原认证机制保持不变。

首轮有相应失败和串行未执行场景，不能计为通过；最终结果以表中完整重跑为准。没有删、禁用或跳过既有测试来掩盖失败。

## Windows 待验收、数据保护和边界

- A6 未在 Windows JVM、NTFS、PowerShell 5.1 或用户 Chrome/Edge 上执行。按 [Windows 运行与验收](A6-PDF文献管理运行与验收.md) 一次完成命令与网页流程后反馈。A5 受限符号链接/POSIX 测试需记录具体跳过原因；A6 关键场景必须实际执行。
- 所有破坏性测试使用 Testcontainers 或独立浏览器容器、私有临时根目录；数据库连接、存储根目录和大小设置显式覆盖本机配置，不操作实际管理员、正式库或原件，不改写 .env、medical-rag-postgres 和 medical-rag-pgdata。Spring Boot 仍可能按既有配置规则加载本机 .env，但隔离测试参数优先，不因此连接正式数据库或使用正式存储目录；不查看或输出配置中的真实密码。跨账号夹具只在事务回滚的测试数据库中放宽约束，产品不增加第二管理员入口。
- A4 的 RestartTestApplication 日志/进程释放修复保持原样；A6 实际 jar 重启继续复用该组件。浏览器启动器增加强制结束后的有限退出等待，不在进程尚存活时删文件根目录。
- 原件仍用 A5 私有目录、UUID、NOFOLLOW/realPath、流式 SHA-256；检测失败不输出 PDF 字节。没有静态 uploads 映射；本机端口仍只绑定回环。
- 当前全文件预览/下载，不实现 Range；普通 PDF.js 预览仍有与文件大小相关的浏览器内存消耗，默认 50 MiB。不宣称病毒扫描或抵御恶意本机管理员；根目录必须由可信账号写入。
- 数据库/文件并非一个硬件原子事务，崩溃意图可人工重试；未知内容不自动扫删。硬件损坏需要数据库和原件一致备份恢复。
- A7 图片、B2 文本提取/清洗/Chunk/重处理、B3 Embedding/向量、后续 RAG/OCR/分类/标注均未实现。上传只能待处理，未增加假功能入口。
