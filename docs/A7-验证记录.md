## 开发中发现与修正

1. Element Plus标签可同时关联combobox/listbox，且selected placeholder覆盖内部input点击。浏览器测试改为点击用户可见的el-select外壳，实际选择选项；不force点击、不跳过交互。首次图片非法响应使用A5真实中文消息断言，退出遵循A2真实204。
2. 统一资料清理显式排序PDF0、图片10，使混合库失败恢复顺序可重现；无级联清理或假成功。相关真实混合测试通过后再交付。
3. PG READ COMMITTED的“计数SELECT+FOR UPDATE”在等上传锁时可能保留旧快照。改先单独锁库，再新SQL读实际数量；以latch协调真实上传/删除、旧expected计数的专项覆盖，断言409且库/图/原件保留。专项在临时恢复旧查询时实际失败（删除未抛出冲突），恢复修复后完整复测；确认不是只复述实现的无效断言。
4. A8隔离启动器持有前后端进程，安全重启仅自建数据库，检测真实停止、重新就绪、BCrypt保持和V5唯一；支持数据库重启端口重新分配，不接受客户端提供容器/PID/路径。子Java强制测试URL/root/caps，排除继承的Spring/JVM配置覆盖；保留A4重启日志组件。
5. A8首轮已完成真实重启，但断言过严地要求无redirect的/login；修正为允许既有安全redirect，认证机制未改。新用户setup仍用真实管理员标签和登录流程。

6. 开发期间一次全套浏览器被并行Maven重建target中的运行jar干扰，造成后端懒加载NoClassDefFoundError与超时。隔离启动器改先复制已构建jar到本次自建目录再运行/重启，防止运行文件被重写；最终后端和浏览器顺序复测，不把当次失败或未运行项目算通过。

上述开发期失败是定位记录，最终成功必须以最终执行统计为准，不算跳过/降断言。没有用任意真实患者或论文文件，图片/PDF均运行时生成的合成夹具。
