## 未验证项与边界

1. **尚未在真实 Windows 电脑执行。** Windows PowerShell 5.1、`mvnw.cmd`、`npm.cmd`、Docker Desktop/WSL 2、中文/空格路径需按 README 实机验收；Linux PowerShell 检查不能代替它们。
2. Node 22 兼容范围来自依赖 engines；本次实际运行的是 Node 24，没有另跑 Node 22。
3. 已有 Windows 原生 PostgreSQL 的替代安装路径未实机验证；已验证推荐的 pgvector Docker 镜像方案。
4. A1 没有登录、账号表、知识库、上传、RAG、模型设置，也没有整站 Compose 或正式 Release。
5. 运行中 Flyway 健康只说明已执行记录可读；启动时 Flyway 执行版本/校验和验证，不宣称已经验证未来业务表。
