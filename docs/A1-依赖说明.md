## 数据库与运行边界

A1 本机开发脚本只初始化数据库容器，没有整站 Docker Compose。镜像固定标签为 `pgvector/pgvector:0.8.2-pg17`；本次拉取 digest 为 `sha256:feb68f4f15446397d8cac7f4fe48fe4586de83160d1fc48b46283312d1a33966`。正式分发时再明确镜像 digest 与平台策略。

数据库外部映射仅 `127.0.0.1:5433`，后端仅 `127.0.0.1:8080`，前端仅 `127.0.0.1:5173`。迁移 V1 只启用 vector 扩展；业务表随任务新增。保留真实迁移记录，重复启动不重复执行。

健康接口会真实查询数据库版本、vector 扩展与向量距离运算、Flyway 已执行记录。它不宣称验证了未来业务表、所有索引或模型服务。启动时由 Flyway 校验迁移；运行时数据库不可达、扩展缺失或迁移历史不可读都返回 HTTP 503。
